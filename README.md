# World of Zuul: Text Adventure Game (Java)

> A story-led text adventure with an inventory, wandering characters, three-word commands and a room that teleports you.

🔒 The code sits in a private repository because this was King's College London coursework. Ask me and I'll walk you through it.

## Overview
I turned a bare text-adventure framework into a full game with a setting, a story and a way to win. You explore rooms, pick up and use items, and talk to characters by typing commands. The game ships as a runnable JAR.

## Features
- Six or more linked locations, with items you can carry and items fixed in place
- An inventory with a weight limit
- A `back` command that retraces every move, using a history stack
- Four or more new commands for items and game mechanics
- **Extras:** characters who move between rooms, a parser that handles three-word commands such as giving an item to someone, and a magic room that sends you somewhere at random
